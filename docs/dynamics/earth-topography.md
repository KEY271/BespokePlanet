# 地球の地形

[地形](./topography.md)は大陸と山脈を解析的な形状の重ね合わせとして生成している。ここでは同じ出力（格子の陸面率 $f_L$、切断したスペクトル $\Phi_s$、診断量）を、地球の標高データから生成する方法を定める。生成は $T=31$ と $T=63$ の両方で同じデータから行う。$f_L$ は格子セル平均のまま使い、切断する $z_s$ だけを切断波数に応じて平滑化して Gibbs リップルを抑える。$\Phi_s$ と $f_L$ の使われ方（$\Phi_s$ は固定の下端境界条件、$f_L$ は[陸と海の混合](../tendency/land-sea-surface.md)だけが使う格子量）は解析的な地形と同じである。

## 全体の流れ

1. **前処理（Python、一度だけ）** ETOPO 2022 の $1'$ 標高を $6'$ おきに点標本し、$0.5^\circ$ の等間隔格子に集計して、各セルの陸面率と陸の平均標高を持つ中間ファイルを作る。これがこの惑星の定義であり、リポジトリに入れてある。
2. **生成（Fortran、実行時）** 中間ファイルを読み、$f_L$ は各格子点の担当領域（緯度リングと経度区間）でセルを面積平均して作る（平滑化しない）。$z_s$ は切断波数 $T$ に応じた幅の Gauss 核で球面上を平滑化して octahedral 格子に載せ、$\Phi_s=gz_s$ をスペクトル変換して切断する。解析的な地形の `generate_topography` と同じ引数・戻り値の形である。
3. **走査（Python）** `scripts/plot_earth_terrain.py` が Fortran と同じ手順を numpy で再現し、平滑化の幅を変えたときの海上の負の行き過ぎ、山の高さ、海上への高さの漏れを表と図にする（[走査の結果](#走査の結果)）。既定の幅はこの走査で選んだ値である。

解析的な地形では形状のパラメータ（海岸の幅 $w$、山脈の半幅 $\sigma$）を $T=31$ の[解像度の条件](./topography.md#解像度との関係)に合わせて選ぶことで $\Phi_s$ の Gibbs リップルを抑えている。地球の地形にはパラメータがないので、同じ役割を $z_s$ の平滑化の幅が担う。平滑化の幅は $T$ に依存させ、$T=63$ では $T=31$ より細かい構造を残す。$f_L$ は切断しない格子量で、地表温度も[格子で持つ](../tendency/land-sea-surface.md#t_s-を格子で持つ理由)ので、海岸の急さに数値上の条件はない。SpeedyWeather や SPEEDY と同じく高解像度のマスクの格子セル平均をそのまま使う。

## データ

NOAA NCEI の ETOPO 2022（v1）を使う。ETOPO 2022 の配布格子は $15''$・$30''$・$60''$ の 3 つで、最も粗い $60''$ でも約 $478\,\mathrm{MB}$ ある。ここでは THREDDS の OPeNDAP から緯度・経度とも 6 画素おきに点標本を取り出し、$6'$（$0.1^\circ$）の $3600\times1800$ 格子（約 $26\,\mathrm{MB}$）として使う。$T=63$ の平滑化の幅 $180^\circ/T\approx2.9^\circ$ に対して十分細かく、全球の取得に 1–2 分で済む。より古い ETOPO5（$5'$、$19\,\mathrm{MB}$）や ETOPO2v2（$2'$、$89\,\mathrm{MB}$）も配布されているが、同じ現行データを間引く方が出自が単純なので使わない。

| 項目 | 値 |
| --- | --- |
| 製品 | ETOPO 2022 v1, 60 arc-second, **ice surface**（氷床の表面高度） |
| 取得 | OPeNDAP `https://www.ngdc.noaa.gov/thredds/dodsC/global/ETOPO2022/60s/60s_surface_elev_netcdf/ETOPO_2022_v1_60s_N90W180_surface.nc` を `z[::6, ::6]` で読む |
| DOI | 10.25921/fd45-gt74 |
| 元の格子 | $21600\times10800$、経度 $-180^\circ\ldots180^\circ$、緯度 $-90^\circ\ldots90^\circ$、セル中心の値（$\pm89.9917^\circ$ から） |
| 間引いた格子 | $3600\times1800$、$0.1^\circ$ 間隔の点標本 |
| 変数 | `z`（m、海は負、陸・氷面は正、`_FillValue` $=-99999$、EGM2008 基準） |

大気モデルの下端境界には氷床の表面が必要なので、基盤岩の `bed` ではなく `surface` を使う。南極・グリーンランドの氷床は $3000$–$4000\,\mathrm{m}$ の高原として現れる。THREDDS の NetCDF Subset Service（`ncss`）はストライド付きの領域指定でサーバー側の境界判定に失敗するので使わない。

## 前処理

`scripts/prepare_earth_topography.py` で行う。netCDF4 は既定の Python 環境に入っていないので `uv run --project ~/.local/share/llm-python --with netCDF4 python scripts/prepare_earth_topography.py` のように一時的に加える（取得済みのキャッシュ `output/etopo2022/` があれば netCDF4 はいらない）。

1. OPeNDAP から緯度 1800 行ずつ間引いて読み、`output/etopo2022/ETOPO_2022_v1_surface_6min_stride.npz` にキャッシュする。`output/` は git 管理外である。
2. 経度を $0^\circ\le\lambda<360^\circ$ に並べ替える（モデルの $\lambda=0$ はグリニッジ）。緯度は元データのまま南から北に並ぶ（モデルの緯度リングと同じ向き）。
3. $0.5^\circ$ のセル（$720\times360$、$5\times5$ 標本）ごとに
   $$
   f^{(0)}=\frac{\text{標本数}(z>0)}{25},\qquad
   h^{(0)}=\frac{1}{25}\sum\max(z,0)
   $$
   を求める。$h^{(0)}$ は海の標本を $0$ として平均した高度で、解析的な地形の $z_s=f_L(h_0+\sum z_r)$ と同じく「陸面率を掛けた高度」の意味を持つ。$f^{(0)}$ は $1/25=4\%$ 刻みになるが、格子点の担当領域（$0.5^\circ$ セルで $T=31$ は約 30 個、$T=63$ は約 7 個）の平均では目立たない。$0.5^\circ$ の中で $\cos\varphi$ の変化は無視する。
4. 中間ファイルと JSON を書き、確認用の図 `scripts/earth_topography_source.png`（$6'$ の標高、$0.5^\circ$ の $f^{(0)}$ と $h^{(0)}$、目印の値）を描く。

陸の判定は $z>0$ とする。この判定で

- 南極の棚氷は氷の表面が正なので陸になる（大気の下端として妥当）。
- 湖（五大湖など）は水面高度が正なので陸になる。
- カスピ海（$-28\,\mathrm{m}$）は海になり、死海周辺やデスバレーなど海面下の陸は海になる。

いずれも $T=63$ の最短波長（約 $5.7^\circ$）より小さいので気候には効かない。海岸線データ（GSHHG など）による判定は使わない。

実行結果（2026-09-22）は全球の陸面率 $\braket{f^{(0)}}=0.291$、$h^{(0)}$ の最大 $5624\,\mathrm{m}$（$80.75^\circ\mathrm{E},35.25^\circ\mathrm{N}$、カラコルム）、チベット（$90^\circ\mathrm{E},33^\circ\mathrm{N}$）$4967\,\mathrm{m}$、南極（$90^\circ\mathrm{E},80^\circ\mathrm{S}$）$3798\,\mathrm{m}$、グリーンランド（$320^\circ\mathrm{E},72^\circ\mathrm{N}$）$3059\,\mathrm{m}$ である。

### 中間ファイル

`core/data/earth_topography_0p5deg.bin` と `core/data/earth_topography_0p5deg.json` の 2 つで、前者がデータ、後者が由来である。

- データはリトルエンディアンの `real64` を並べたストリームで、出力ファイルと同じ形式である。$f^{(0)}$ の $720\times360$ 個に続けて $h^{(0)}$ の $720\times360$ 個を置く（$4{,}147{,}200$ バイト）。それぞれ経度が最も速く変わり、セル中心は
  $$
  \lambda_i=(i-\tfrac12)\cdot0.5^\circ\ (i=1,\dots,720),\qquad
  \varphi_j=-90^\circ+(j-\tfrac12)\cdot0.5^\circ\ (j=1,\dots,360)
  $$
  である。
- JSON には取得元 URL・DOI・間引きの方法、陸の判定 $z>0$、格子の定義、生成日、中間ファイルの SHA-256、全球の陸面率 $\braket{f^{(0)}}$（$\cos\varphi$ 重み）、$h^{(0)}$ の最大値と位置、目印の格子点の値を書く。

$0.5^\circ$ は $T=63$ の格子間隔（約 $1.4^\circ$）の $1/3$ 弱、平滑化の幅（後述、約 $2.9^\circ$）の $1/6$ で、格子セル平均と平滑化の前の構造を十分に表せる。$0.25^\circ$ にするとファイルが $16\,\mathrm{MB}$ になるので採らない。ETOPO の標本のキャッシュはリポジトリに入れない。

## 生成

Fortran のモジュール `earth_topography` の `generate_earth_topography(transform, config, land_fraction, target_height, surface_geopotential, truncated_height, diagnostics)` が生成する。引数の並びと型は `generate_topography` と同じで、`analytic_height` の位置に平滑化した目標高度 `target_height` を返す。中間ファイルは `read_earth_topography_data` が大きさと値域（$0\le f^{(0)}\le1$、$0\le h^{(0)}\le9000\,\mathrm{m}$）を検査して読む。設定型 `earth_topography_config` は次を持つ。

| 設定 | 既定値 | 意味 |
| --- | --- | --- |
| `data_path` | `data/earth_topography_0p5deg.bin` | 中間ファイル。`core/` から実行するので相対パス。見つからなければ `core/data/...` も試す |
| `kernel_scale_factor` $c$ | $1.0$ | $z_s$ の平滑化の幅 $s=c\cdot180^\circ/T$（$f_L$ には掛けない） |
| `window_factor` | $3$ | 核を打ち切る半径（$s$ の倍数） |
| `residual_filter_strength` $\kappa$ | $0$（無効） | 切断後に残るリップルを落とすスペクトルフィルターの強さ |
| `open_ocean_land_fraction` | $0.01$ | 診断で海とみなす陸面率の上限 |

### 陸面率

格子点 $(\lambda_i,\varphi_j)$ の担当領域を、緯度は隣のリングとの中点、経度は最も近い格子点の経度区間とし、その中に中心を持つ $0.5^\circ$ セルの $f^{(0)}$ を面積（$\cos\varphi$）で平均して $f_L$ とする。$f^{(0)}\in[0,1]$ の面積平均なので $0\le f_L\le1$ である。平滑化も切断もしないので、$T=31$（格子間隔約 $2.8^\circ$）でも幅が格子間隔より狭い海峡や地峡はその割合の陸面率として残る（中米は $0.3$–$0.8$、地中海は $0.1$–$0.3$、日本 $0.5$、紅海 $0.5$、黒海・ハドソン湾・メキシコ湾は $0$）。$T=63$（約 $1.4^\circ$）ではパナマ $0.5$、ニカラグア $1$、日本 $1$、地中海東部 $0$ になる。全球の陸面率は $\braket{f^{(0)}}=0.2908$ に対して $0.2906$ で、$T$ に依らない。

$f_L$ を平滑化しないのは、$f_L$ を使う地表収支の $T_s$ が[格子量](../tendency/land-sea-surface.md#t_s-を格子で持つ理由)で、海岸の急さが数値に影響しないからである。以前は $T_s$ をスペクトルで持っていたため、$f_L$ を $z_s$ と同じ核（$T=31$ で $7.3^\circ$）で平滑化しており、中米が海に沈み、地中海が陸に埋まっていた。

### 平滑化

$z_s$ は、格子点 $(\lambda,\varphi)$ と中間格子のセル $(\lambda_i,\varphi_j)$ との大円距離 $\theta$ を使って

$$
z_s(\lambda,\varphi)=\frac{\sum_{ij}W_{ij}h^{(0)}_{ij}}{\sum_{ij}W_{ij}},\qquad
W_{ij}=\cos\varphi_j\exp\left[-\left(\frac{\theta_{ij}}{s}\right)^2\right]
$$

とする。和は $\theta\le3s$ のセルに限り、重みはその範囲で規格化する。$\cos\varphi_j$ はセルの面積である。大円距離は単位ベクトルの内積から求め、極を含む格子点では全経度を対象にする。$h^{(0)}\ge0$ の重み付き平均なので $z_s\ge0$ が自動的に保証される。

$f_L$ を平滑化せず $z_s$ を平滑化するので、海岸の山の裾は $f_L=0$ の海上に $3s$ まで広がり、「山の裾なのに海」という格子点ができる。南極の縁とグリーンランドの周りで大きく、$f_L<0.01$ の海上の $z_s$ は最大で $T=31$ で約 $780\,\mathrm{m}$、$T=63$ で約 $950\,\mathrm{m}$、RMS で $68$・$45\,\mathrm{m}$ である（後述の診断）。これは切断波数で表せる地形の限界であり、陸海マスクを格子で持つどのスペクトルモデルでも起きる。海上の $z_s>0$ は $p_s$ を静水圧のぶんだけ下げるだけで、その海面の温度は $f_L=0$ の slab ocean として進む。

核の幅は

$$
s=c\,\frac{180^\circ}{T}
$$

とし、既定で $c=1.0$、すなわち $T=31$ で $s\approx5.8^\circ$、$T=63$ で $s\approx2.9^\circ$ とする。$c=1.0$ は下の基準（Gibbs リップル）を満たす最小の値として[走査](#走査の結果)で選んだ値で、切断波数でのスペクトル応答から次のように解釈できる。

- **切断波数でのスペクトル応答** 球面上の Gauss 核は熱核で近似でき、球面調和係数に
  $$
  F(n)\approx\exp\left[-\frac{n(n+1)s^2}{4}\right]\qquad(s\text{ はラジアン})
  $$
  を掛けるのと同じである。$s=c\pi/T$ を入れると切断波数での応答は $F(T)\approx\exp(-\pi^2c^2/4)$ で、

  | $c$ | $0.5$ | $0.75$ | $1.0$ | $1.25$ |
  | --- | --- | --- | --- | --- |
  | $F(T)$ | $0.54$ | $0.25$ | $0.085$ | $0.021$ |
  | $s$（$T=31$） | $2.9^\circ$ | $4.4^\circ$ | $5.8^\circ$ | $7.3^\circ$ |
  | $s$（$T=63$） | $1.4^\circ$ | $2.1^\circ$ | $2.9^\circ$ | $3.6^\circ$ |

  である。切断で落とされる $n>T$ の成分が小さいほど Gibbs リップルは小さい。$c=1.0$ では切断波数の成分が平滑化前の $8.5\%$ に落ちており、走査では $c=0.75$（$25\%$）でアンデス沖の負の行き過ぎが $-60\,\mathrm{m}$ 台になって基準を外れ、$c=1.0$ で $-11$〜$-23\,\mathrm{m}$ に収まる。

### 切断と残差フィルター

$\Phi_s=gz_s$ を格子で作り、`grid_to_spectral` で $T$ まで切断する。[JW](./Jablonowski-Williamson.md#地表ジオポテンシャル) や解析的な地形と同じ扱いである。既定では平滑化だけで後述の基準を満たすので $\kappa=0$ で無効にしてあるが、切断後の海上の負の行き過ぎが基準に収まらないときの手段として

$$
\Phi_s{}^m_n\leftarrow\Phi_s{}^m_n\exp\left[-\kappa\left(\frac{n(n+1)}{T(T+1)}\right)^2\right]
$$

がある（Hoskins 1980 と同じ形）。$\kappa=0$ で無効、$\kappa=\ln 10\approx2.3$ で $n=T$ の成分が $1/10$ になる。$\kappa$ は切断波数近くだけを落とすので $c$ を上げるより山を保てるが、格子の $z_s$ と平滑化した目標の関係が単純でなくなるので、$c$ を上げても基準を満たせないときだけ使う。

切断後の $\Phi_s$ を `spectral_to_grid` で格子に戻した値を `truncated_height`（$z_s$、m）として出力する。海上でも厳密には $0$ でなく、負の値をとる点がある。**格子で負の値を $0$ に置き換えてはならない**。モデルが見るのはスペクトルの $\Phi_s$ であり、格子の値だけを直すと出力とモデルの状態が食い違う。

## Gibbs 現象への配慮

### どこで問題になるか

地球の地形には解析的な地形にない急な段差が多い。

- **海岸の直後に立つ山脈** アンデス（幅約 $300\,\mathrm{km}$、高さ $4000\,\mathrm{m}$ 超）、ロッキー山脈西側、ヒマラヤ南縁。幅は $T=63$ の最短波長より狭い。
- **氷床の縁** 南極は約 $70^\circ\mathrm{S}$ で $0$ から $2000\,\mathrm{m}$ 超に立ち上がる。帯状に近い段差なので、切断したままだと南大洋全体に緯度方向のリップルが出る。グリーンランドも同様である。
- **海岸線そのもの** 陸の基準高度の $0\to h$ の段差。

リップルは 2 か所で効く。

1. **海上の $\Phi_s$** 気圧傾度項を通じて定在的な強制になる。海上の $z_s$ が $\pm20\,\mathrm{m}$ なら $p_s$ の偏差は $\rho g\Delta z\approx\pm2.4\,\mathrm{hPa}$ である。負の $z_s$ では初期値の $p_s>p_0$ になる（[地形上の初期状態](./topography.md#地表面気圧)）。
2. **$\nabla\Phi_s$** 切断波数近くの成分が大きいと発散の傾向に格子スケールの雑音が入る。大気側は超粘性で減衰するが、$\Phi_s$ 自体は減衰しないので強制は続く。

$f_L$ は切断せず、$f_L$ を使う地表温度は格子で持つので、$f_L$ の海岸の段差は Gibbs リップルの原因にならない。

### 採る対策

- $z_s$ を物理空間で $T$ に応じた幅の Gauss 核で平滑化してから切断する（上記）。$f_L$ は平滑化も切断もしない。
- 平滑化の幅は $c$ の 1 つで決め、$T=31$ と $T=63$ で同じ $c$ を使う。$T$ が上がれば $s$ は自動的に細くなる。
- 生成のたびに下の診断を求めてメタデータに書く。基準を満たさない場合の調整は $c$ を上げることで行う。
- 残差フィルター $\kappa$ は最後の手段とする。

### 採らない対策

- **格子の $z_s<0$ を $0$ に置き換える** スペクトルの $\Phi_s$ と食い違う（上記）。
- **海上のリップルを最小化する反復（Navarra et al. 1994、Bouteloup 1995）** 切断後に海上を $0$ に戻して再解析する反復で、海上のリップルは減るが陸の値が変わり、$f_L$ との整合が崩れる。平滑化で基準を満たせる限り使わない。
- **エンベロープ地形（Wallace et al. 1983）** 平均高度に格子内の標準偏差を加えて山を高くする方法。ここでは平均高度を使い、山の低さは解像度の限界として受け入れる。
- **$f_L$ のスペクトル切断** $[0,1]$ を外れる。
- **$f_L$ の平滑化** 地表温度を格子で持つ限り数値上の必要がなく、$T=31$ では中米・地中海・日本のような格子間隔以下の陸海を消してしまう（以前の実装）。$z_s$ の裾が海上に広がる不整合は、$f_L$ をぼかしてマスクの方を地形に合わせるより、地形の解像度の限界として受け入れる。

### 代償

平滑化は山を低くする。幅 $W$ の細い山脈の頂上は $H\,W/(s\sqrt\pi)$ 程度に、半幅 $a$ の高原の中央は $H\operatorname{erf}(a/s)$ 程度になる。走査スクリプトで測った切断後の $z_s$（$c=1.0$、最も近い格子点）は

| 地形 | $0.5^\circ$ セル | $T=31$（$s=5.8^\circ$） | $T=63$（$s=2.9^\circ$） |
| --- | --- | --- | --- |
| チベット高原（$90^\circ\mathrm{E},33^\circ\mathrm{N}$） | $4967$ | $3797$ | $4863$ |
| アンデス高原（$292^\circ\mathrm{E},18^\circ\mathrm{S}$） | $3958$ | $1547$ | $2558$ |
| 南極（$90^\circ\mathrm{E},80^\circ\mathrm{S}$） | $3798$ | $3256$ | $3635$ |
| グリーンランド（$320^\circ\mathrm{E},72^\circ\mathrm{N}$） | $3059$ | $1461$ | $2450$ |
| 全球最大 | $5624$ | $3797$ | $4913$ |

である（m）。$T=31$ ではアンデスとグリーンランドが $40$–$50\%$ になり、雨陰やロッキーの定在波は弱くなる。これは $T=31$ の解像度の限界である。もう一つの代償は上述の海上への高さの漏れで、$f_L<0.01$ の海上の $z_s$ は RMS で $68$（$T=31$）・$45\,\mathrm{m}$（$T=63$）、最大 $779$・$952\,\mathrm{m}$（南極の縁）である。$c$ を上げると漏れは増え（$c=1.25$ で $84$・$58\,\mathrm{m}$）、下げると Gibbs リップルが増えるので、$c$ はこの 2 つの間の取り引きでもある。

## 診断

生成時に次を求めてメタデータに書く。解析的な地形の「解析形との RMS 差」は、目標の $z_s$ 自体が $T$ に依存するので 2 つに分ける。

- 全球の陸面率 $\braket{f_L}$（Gauss 重み）。中間ファイルの $\braket{f^{(0)}}$ と、$T=31$ と $T=63$ の間で比べる。
- 格子の $z_s$ の最大値とその位置、最小値とその位置。
- **切断誤差** 平滑化した目標 $z_s$ と切断後の $z_s$ の差の全球 RMS。Gibbs リップルの大きさを表す。
- **総合誤差** 中間ファイルの $h^{(0)}$ を各格子点の担当領域（緯度リングと経度区間）で面積平均した $h_{\mathrm{raw}}$ と、切断後の $z_s$ の差の全球 RMS。平滑化と切断を合わせた誤差で、$T=63$ で $T=31$ より小さくなる。
- **外洋のリップル** 陸から核の届かない格子点、すなわち $f^{(0)}$ を $z_s$ と同じ核で平滑化した値（診断のためだけに計算する）が $0.01$ 未満の格子点における、切断後 $z_s$ の RMS と最小値。ここでは平滑化した目標の $z_s$ が $0$ なので、残るのは切断の Gibbs リップルだけである。
- **海上への高さの漏れ** 格子の $f_L<0.01$ の全格子点（沿岸を含む）における切断後 $z_s$ の RMS と最大値。平滑化が海岸を越えて広げた陸の高さの大きさを表す。

$c$ を決める基準は、解析的な地形と同じく

- 切断後の $z_s$ の最小値が $-50\,\mathrm{m}$ を下回らない、
- 外洋の $z_s$ の RMS が $10\,\mathrm{m}$ 以下、

の 2 つで、$0.25$ 刻みの走査で両解像度とも基準を満たす最小の $c$ を採る。$c>1.5$ が必要になる場合は $T=31$ の山が低すぎるので、$c=1.5$ に留めて $\kappa$ で残りを落とす方針である。

## 力学への影響

[地形](./topography.md#力学への影響)に加えて次に注意する。

- 地表面気圧の反復はすべての格子点で収束し、チベットと南極の上では $p_s$ が $T=31$ で $611\,\mathrm{hPa}$、$T=63$ で $553\,\mathrm{hPa}$ まで下がる。重力波の陰的演算子の参照状態 $p_s=p_0$ との差は解析的な地形（約 $20\%$）より大きい。参照温度 $300\,\mathrm{K}$ が実際より高い側にあるので安定性は保たれる。物理過程なしの乾燥大気を $\Delta t=1200\,\mathrm{s}$ で 1 日積分した発散の RMS は平坦地形の $2\times10^{-7}\,\mathrm{s^{-1}}$ に対して、解析的な地形で $7$–$8\times10^{-7}$、地球の地形で $7.5\times10^{-7}$（$T=31$）・$1.6\times10^{-6}$（$T=63$）である。最大の南北風は解析的な地形の $10$–$15\,\mathrm{m\,s^{-1}}$ に対して $14$（$T=31$）・$31\,\mathrm{m\,s^{-1}}$（$T=63$）で、3 日目まで緩やかに増える。JW の基本場は傾圧不安定なので、地形の擾乱から波が育つのは想定どおりであり、発散が桁で増えていないことから数値不安定ではないと判断する。平坦地形は $v\equiv0$ から始まるので、南北風の比較の基準には解析的な地形を使う。
- [hybrid-sigma 座標](./hybrid-sigma.md)の half level の気圧は $p_s>267\,\mathrm{hPa}$ で単調なので、地球のどこでも層の順序は保たれる。
- 高原の上では初期の $T_N$ が JW の減率で $15$–$20\,\mathrm{K}$ 低く、$T_s=T_d=T_N$ から始まる。

## 出力

解析的な地形と同じく、時間に依らない格子の場として $f_L$（`land_fraction.bin`）と切断後の $z_s$（`surface_height.bin`）を一度だけ書く。メタデータの `topography` には、形状の一覧の代わりに元データと DOI（`source`）、中間ファイルのパス（`data_file`）と由来 JSON のパス（`data_description`）、陸の判定（`land_definition`）、$f_L$ と $z_s$ の作り方（`method`）、$c$（`kernel_scale_factor`）、$s$（`kernel_half_width_degrees`、度）、窓の倍数（`window_factor`）、$\kappa$（`residual_filter_strength`）、外洋の定義（`open_ocean_land_fraction`、`open_ocean_definition`）、中間ファイルの全球陸面率と最大高度（`source_global_land_fraction`、`source_maximum_height_m`）、上の診断量を書く。中間ファイルの SHA-256 は由来 JSON にあり、メタデータには写さない。
