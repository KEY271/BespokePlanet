# Slab ocean ケース

[放射ケース](./radiation.md)の地面を、深さ 30 m の一層の [slab ocean](../tendency/slab-ocean.md) に置き換えた計算ケースである。

## 放射ケースとの差分

次の2点だけを放射ケースから変更する。

- 地面の浅層温度 $T_s$ と深層温度 $T_d$ は用いず、海洋温度 $T_o$ だけを時間発展させる。海流や海洋内・海洋間の熱輸送は扱わない。
- 地軸の傾きを $0$ とする。このため太陽赤緯は一年を通じて $0$ であり、日変化は残るが季節変化はない。

短波アルベドを含む放射の係数、乾燥対流調節、地表摩擦、上層の Rayleigh 摩擦、暦、自転角速度、初期大気、計算期間、タイムステップおよび出力間隔は放射ケースと同じとする。海洋温度の初期値は、放射ケースの地面温度と同じく大気最下層の初期温度に等しくする。

## 出力

放射ケースの出力において、地表温度 $T_s$ を海洋温度 $T_o$ と読み替える。地面下層温度 $T_d$ は slab ocean に存在しないため出力しない。その他の日平均、月平均および毎年の瞬時値は放射ケースと同じとする。
