# 乾燥大気のケース

[乾燥大気](../dynamics/dry.md)の計算手法を、物理過程を加えずに積分するケースの定義である。

## 初期状態

初期値 $X^0$ と地表ジオポテンシャル $\Phi_s$ には [Jablonowski–Williamson の初期状態](../dynamics/Jablonowski-Williamson.md)を用いる。基本場だけを与えて定常性を調べるケースと、東西風に局所的な擾乱を加えて傾圧波を発達させるケースの二つを走らせる。

## 物理過程

物理過程は持たないので、外力は $\bm{F}_k=0$、物理過程の項は $\mathcal{P}=0$ である。

## 時間

$10$ 日間シミュレーションする。タイムステップは $\Delta t=1200\,\mathrm{s}$ で他の計算と同じとし、出力は $16$ ステップごとに保存する。
