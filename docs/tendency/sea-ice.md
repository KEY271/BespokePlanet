# 海氷と陸海別温度

状態: **実装済み**。海氷の局所熱力学、陸海別温度、放射・蒸発との結合、LeapFrog・RAW、日次診断、月平均・年次出力と可視化の仕様を記述する。数値検証は `core/test/check_sea_ice.f90` にある。

## 1. 扱う範囲と設定

海の中の海氷面積率 $A$ と海氷体積 $V$ を予報し、陸面温度 $T_L$ と海水温 $T_o$ を分ける。氷厚は $h=V/A$、海氷表面温度 $T_s$ は熱容量を持たない診断変数とする。開水面での生成・融解、氷表面の融解、底面の成長・融解を扱う。

指定値は $T_f=271.35\,\mathrm K$、新氷厚 $h_0=0.5\,\mathrm m$、熱伝導率 $k=2\,\mathrm{W\,m^{-1}\,K^{-1}}$、表面温度上限 $T_m=273.15\,\mathrm K$ とする。融解時の面積は $A\propto\sqrt V$ に従って更新する。

採用した設定と規約は次のとおり。式と境界処理は後続節に記す。

| 項目 | 仕様 |
| --- | --- |
| 面積・体積の分母 | $A$ は格子内の海面積に対する割合、$V$ は海面積当たりの氷体積。$V$ の単位は m |
| 海水の熱容量 | 氷の下を含む海全体に $C_o$ を持たせ、開水面フラックスに一度だけ $1-A$ を掛ける |
| 相平衡 | 氷が残る海水は $T_o=T_f$。氷がなければ $T_o\ge T_f$ |
| 氷の定数 | $\rho_i=917\,\mathrm{kg\,m^{-3}}$、$L_f=3.34\times10^5\,\mathrm{J\,kg^{-1}}$、裸氷アルベド $\alpha_i=0.60$ |
| 氷面の水蒸気交換 | 今回は昇華・凝華をともに 0 とする。開水面と陸面の蒸発・結露は継続する |
| 底面伝導の符号 | $T_s>T_f$ なら $\Delta V_{\rm ice}<0$ として底面融解を許す |
| 同時に生成・融解する場合 | 新氷の面積を加えた後、合計 $\Delta V<0$ なら面積全体に $\sqrt{V^{\rm new}/V}$ を掛ける。分母は更新前の体積 |
| 地中温度 | $T_d$ と $C_d$ を陸面積当たりに統一する。海岸の地中熱容量の意味も変更する |
| 時間積分 | 既存の前時刻物理・LeapFrog・RAW を使い、RAW 後に海水と氷の合計エネルギーを保つ相平衡補正を行う |
| 有効化 | 湿潤海洋ケースと陸海ケースで海氷を有効にする。乾燥の既存検証ケースは既定で無効のまま |

氷上の積雪、氷の移流・変形、融解池、塩分・ブライン、氷内の顕熱、氷を透過する短波、海流は扱わない。海洋の熱輸送は [Q flux](./q-flux.md) として海全体の混合層へ与え、5.1 節の $Q_{\rm ow}$ に加える（同ページの[海洋の熱収支への加え方](./q-flux.md#海洋の熱収支への加え方)）。以下の式は $Q=0$ の場合を書く。氷上の降水を $V$ に直接は加えない。[降雪](./snow.md)を有効にしたケースでは、海に落ちた雪を積もらせずに $Q$ から $L_fS_{\rm ls}$ を引いて混合層の熱で融かす（[海に落ちた雪](./snow.md#6-海に落ちた雪)）ので、氷がある格子では同じ質量相当の氷が成長する。海洋水量・塩分・海面高度は予報せず、海水と氷の相変化によって slab の深さや $C_o$ は変えない。

## 2. 従来の実装からの変更

従来の陸海混合は、海岸格子でも `surface_temperature` を一つだけ持ち、熱容量・アルベド・地中交換係数を混ぜていた。現在の[陸と海の混合](./land-sea-surface.md)では温度を分離する。

今回のタイル化では、陸、開水面、海氷が同じ大気柱と接し、それぞれの表面温度で熱交換する。温度を平均してから長波や蒸発を計算する方式にはしない。現在の `surface_temperature` という出力名は面積平均の診断値として残し、物理計算は各タイルの温度を直接使う。

実装上、主に変更する箇所は [状態](../../core/src/state/dry_state.f90)、[物理設定](../../core/src/config/dry_physics_config.f90)、[放射](../../core/src/dry_radiation.f90)、[蒸発傾向](../../core/src/tendency/dry/dry_evaporation_tendency.f90)、[積分器](../../core/src/integration/dry_stepper.f90) と、それらを接続する workspace・初期化・診断・出力である。

## 3. 状態量・面積・定数

時間不変の陸面率を $f_L$、海面率を $f_O=1-f_L$ とする。格子全体に対する各タイルの面積率は

$$
w_L=f_L,\qquad w_{\rm ow}=f_O(1-A),\qquad w_i=f_OA,
\qquad w_L+w_{\rm ow}+w_i=1.
$$

| 量 | 種別 | 定義・単位 |
| --- | --- | --- |
| $T_L$ | 予報 | 陸の浅い層の温度、K |
| $T_d$ | 予報 | 陸の深い層の温度、K |
| $T_o$ | 予報 | 氷の下を含む、一様な海洋混合層の温度、K |
| $A$ | 予報 | 氷面積 / 海面積、無次元 |
| $V$ | 予報 | 氷体積 / 海面積、$\mathrm{m^3/m^2=m}$ |
| $h$ | 診断 | 氷に覆われた部分の厚さ $V/A$、m |
| $T_s$ | 診断 | 海氷の表面温度、K |
| $W$ | 既存の予報 | 陸面積当たりのバケツ水量、$\mathrm{kg\,m^{-2}}$ |

物理的な氷体積は「格子面積 $\times f_OV$」であり、「格子面積 $\times f_OAV$」ではない。$A$ は氷表面のフラックスを体積変化へ換算するときに掛ける。

海洋の熱容量は既存の [slab ocean](./slab-ocean.md) と同じく

$$
C_o=\rho_oc_oh_o=1000\times4186\times30
=1.2558\times10^8\,\mathrm{J\,m^{-2}\,K^{-1}}
$$

とする。これは**海面積当たり**の値で、$(1-A)C_o$ にはしない。氷の単位体積当たりの融解潜熱を

$$
\mathcal L=\rho_iL_f=3.06278\times10^8\,\mathrm{J\,m^{-3}}
$$

と定義する。以下では熱量を体積へ換算するとき必ず $\mathcal L$ で割る。蒸発の潜熱 $L_v$ と融解の潜熱 $L_f$ は別の定数である。

$A=V=0$ を無氷状態とする。氷が存在する場合は $0<A\le1$、$V>0$ を要求する。$A=0$ のとき $V/A$ を評価しない。$h_0$ は新氷が占める面積を決める厚さであり、既存氷の最小厚さではない。

## 4. 陸・開水面・海氷の表面フラックス

雲の反射を引いた地表下向き短波を $S_\downarrow$、下向き長波を $L_\downarrow$ とする。どちらも格子内の各タイルへ共通に与える。以下の $F$ はそれぞれの**タイル面積当たり**の正味フラックスで、表面へ入る向きを正とする。

$$
\begin{aligned}
F_L(T_L)&=(1-\alpha_L)S_\downarrow+L_\downarrow
-\sigma T_L^4-H_L(T_L)-L_vE_L(T_L),\\
F_{\rm ow}(T_o)&=(1-\alpha_o)S_\downarrow+L_\downarrow
-\sigma T_o^4-H_o(T_o)-L_vE_o(T_o),\\
F_i(T_s)&=(1-\alpha_i)S_\downarrow+L_\downarrow
-\sigma T_s^4-H_i(T_s).
\end{aligned}
$$

アルベドは $\alpha_L=0.20$、$\alpha_o=0.06$、$\alpha_i=0.60$ とする。氷の値は一定のモデルパラメーターであり、雪や融解池による変化を含まない。陸の値は[積雪](./snow.md#52-地表フラックスへの効果)があれば $\alpha_L+0.4f$ に、陸の顕熱と蒸発は $1-f$ 倍になる。

顕熱は既存の [地面](./ground.md) と同じ式を各温度 $T_x$ で評価する。

$$
H_x(T_x)=B_H(T_x-T_a^*),\quad
B_H=\rho_Nc_pC_H\sqrt{u_N^2+v_N^2+U_g^2},\quad
T_a^*=T_N(p_s/p_N)^\kappa.
$$

初版では氷面も同じ交換係数を使う。陸の $E_L$ は $T_L$ とバケツ水量から、開水面の $E_o$ は $T_o$ と海面湿潤度から**別々に**求める。陸の利用可能水量による制限と、蒸発無効時に $E_L=E_o=0$ とする既存の設定は維持する。海氷の昇華・凝華は 0 とし、氷面の潜熱項と大気への氷由来の水蒸気源をともに加えない。

陸の二層は陸面積当たりに

$$
C_L\frac{dT_L}{dt}=F_L-H_{Ld},\qquad
C_d\frac{dT_d}{dt}=H_{Ld},\qquad
H_{Ld}=K_{sd}(T_L-T_d)
$$

と進める。$C_L=2\times10^6$、$C_d=2\times10^7\,\mathrm{J\,m^{-2}\,K^{-1}}$、$K_{sd}=2\,\mathrm{W\,m^{-2}\,K^{-1}}$ は既存値を使う。各温度更新を $f_L$ で割らず、大気との交換と格子全体の蓄熱量に $f_L$ を掛ける。これは既存の海岸格子の $C_d/f_L$ 相当という扱いも変更する。

## 5. 海水と氷の一回の物理更新

ここでの $\Delta\tau>0$ は実際に状態を進める時間幅とする。右辺の $A,V,h,T_o$ はすべて更新開始時の値。新しく作った氷の表面フラックスは次の物理評価から計算する。

### 5.1 開水面から海へ入る熱

まず指定どおり、開水面の熱収支だけで仮の海水温を求める。

$$
Q_{\rm ow}=\Delta\tau(1-A)F_{\rm ow}(T_o),\qquad
T_o^*=T_o+\frac{Q_{\rm ow}}{C_o},\qquad
Q_f=C_o(T_o^*-T_f).
$$

$Q_{\rm ow},Q_f$ は海面積当たりの熱量、$\mathrm{J\,m^{-2}}$。ここで $f_O$ を掛けず、$1-A$ で熱容量を割らない。$A=1$ なら開水面からの熱入力は 0 になる。

相変化の候補は次のようにする。

| 条件 | $\Delta V_{\rm ow}$ | 海水温の仮の確定値 $\widehat T_o$ | 新氷による面積増分 |
| --- | --- | --- | --- |
| $Q_f<0$ | $-Q_f/\mathcal L>0$ | $T_f$ | $\Delta A_{\rm ow}=\min(1-A,\Delta V_{\rm ow}/h_0)$ |
| $Q_f>0$ かつ $V>0$ | $-Q_f/\mathcal L<0$ | $T_f$ | 0 |
| $Q_f\ge0$ かつ $V=0$ | 0 | $T_o^*$ | 0 |
| $Q_f=0$ かつ $V>0$ | 0 | $T_f$ | 0 |

氷がない暖かい海では、海水の顕熱を架空の氷の融解に置き換えない。氷があるときは $\Delta V_{\rm ow}$ をこの段階で $-V$ に制限せず、他の二項と合計した後に氷の消滅と余剰熱を処理する。

新氷が残りの開水面をすべて埋めても余る場合、$A$ の増加だけを $1-A$ に制限し、$\Delta V_{\rm ow}$ は全量を保存する。余りは平均氷厚の増加になる。

### 5.2 氷の表面温度

更新開始時に $A>0,V>0$ の場合だけ、$h=V/A$ を求める。底面から表面へ上向きに伝わる熱を

$$
q_c(T)=\frac{k(T_f-T)}{h}
$$

とし、氷の表面収支を

$$
G(T)=F_i(T)+q_c(T)
$$

で表す。表面が融けなければ $G(T_s)=0$ を満たす $T_s$ を求める。

- $G(T_m)\le0$ なら $T_s\le T_m$ の根を求め、表面融解熱 $M=0$ とする。
- $G(T_m)>0$ なら自由な解が $T_m$ を超えるので、$T_s=T_m$ に固定し、$M=G(T_m)>0$ とする。

この $M$ は表面に残る正の熱であり、表面融解に使う。$F_i(T_m)$ だけを融解熱として使うと伝導分を二重計上する。

今回の式では

$$
G'(T)=-4\sigma T^3-B_H-k/h<0\qquad(T\ge0)
$$

なので根は一意である。解法は符号を挟んだ二分法とし、$[0,T_m]$ で探索する。下端でも符号を挟めない、非有限値、反復上限への到達は失敗として扱い、任意の表面温度で続行しない。

薄氷で $k/h$ を巨大な係数として扱わないよう、根の計算自体には

$$
\widetilde G(T)=hF_i(T)+k(T_f-T)
$$

を使う。非融解枝の体積更新用伝導熱は収支から $q_c=-F_i(T_s)$ と評価すると、$T_f-T_s$ の桁落ちを避けつつ熱収支を閉じられる。温度許容幅 $10^{-7}\,\mathrm K$、フラックス許容誤差 $10^{-5}\,\mathrm{W\,m^{-2}}$、反復上限 100 回を既定値とし、スケーリングした式の残差には浮動小数点の丸め誤差も許容する。温度幅だけで打ち切らず残差も検査する。診断にはスケーリングした伝導式の残差も残す。

$A=V=0$ ではこの解法を呼ばず、$\Delta V_{\rm surf}=\Delta V_{\rm ice}=0$ とする。

### 5.3 表面融解と底面成長・融解

海面積当たりの体積変化は

$$
\boxed{\Delta V_{\rm surf}=-\frac{\Delta\tau A M}{\mathcal L}\le0},
\qquad
\boxed{\Delta V_{\rm ice}=\frac{\Delta\tau A q_c(T_s)}{\mathcal L}}.
$$

$T_s<T_f$ なら上向き伝導によって底面で海水が凍る。$T_s=T_f$ なら底面変化は 0。$T_f<T_s\le T_m$ なら $q_c<0$ となり、表面から底へ伝わる熱で底面が融ける。**$\Delta V_{\rm ice}$ の負値を 0 に切り上げない。**

底面から出る $q_c$ は、海水が $T_f$ のまま凍る潜熱の放出として計上する。$\Delta V_{\rm ice}$ を加えるのと同時に、同じ $Aq_c$ を海水の顕熱からさらに引いて $T_o$ を下げる処理は行わない。

この定義では、融解枝・非融解枝の両方で

$$
-\mathcal L(\Delta V_{\rm surf}+\Delta V_{\rm ice})
=\Delta\tau A F_i(T_s)
$$

が成り立つ。数値計算でもこの恒等式を検査する。

### 5.4 合計体積と面積

三つの項はそれぞれを途中でクリップせず合計する。

$$
\Delta V=\Delta V_{\rm ow}+\Delta V_{\rm surf}+\Delta V_{\rm ice},\qquad
V^\dagger=V+\Delta V.
$$

$V^\dagger>0$ の場合、開水面で生じた新氷の面積を加え、正味の融解時は $A\propto\sqrt V$ に従って面積全体を縮める。

$$
A^\dagger=
\begin{cases}
(A+\Delta A_{\rm ow})\sqrt{V^\dagger/V},&\Delta V<0\ \text{かつ}\ V>0,\\
A+\Delta A_{\rm ow},&\text{それ以外},
\end{cases}
$$

$$
A^{\rm new}=\min(1,\max(0,A^\dagger)),\quad
V^{\rm new}=V^\dagger,\quad T_o^{\rm new}=\widehat T_o.
$$

体積比の分母 $V$ は**更新前**の値とし、三項を合計した $\Delta V$ で融解を判定する。底面成長だけでは面積を増やさない。$\Delta V=0$ でも開水面で新氷が生じていれば $\Delta A_{\rm ow}>0$ による面積増加は残る。

新氷生成がない場合、$dA/A=dV/(2V)$ の積分形に一致する。$V^\dagger\to0$ で $A^\dagger$ も連続的に 0 へ近づく。$V^\dagger\le0$ では平方根を評価せず、次節の完全消滅と余剰熱処理へ進む。

### 5.5 完全消滅と余剰熱

$V^\dagger\le0$ の場合は

$$
V^{\rm new}=0,\qquad A^{\rm new}=0,\qquad
Q_{\rm excess}=\mathcal L\max(-V^\dagger,0),\qquad
T_o^{\rm new}=\widehat T_o+\frac{Q_{\rm excess}}{C_o}
$$

とする。融解を伴う通常の枝では $\widehat T_o=T_f$。無氷の暖水枝では $V^\dagger=0$、$Q_{\rm excess}=0$ なので $T_o^*$ がそのまま残る。

余剰熱は開水面・氷表面・底面のどの融解源から来ても一度だけ海水に戻す。$V^\dagger=0$ ちょうどなら余剰熱も 0 とする。氷が途中で消える時間は初版では解かず、開始時のタイル面積で区間全体の外部フラックスを評価する。このため一度の更新で大幅に面積が変わる場合は時間離散化誤差が増えるが、上記の熱量は捨てない。

## 6. 局所エネルギー収支

海水と海氷の、海面積当たりのエネルギーを

$$
\mathcal E_o=C_o(T_o-T_f)-\mathcal L V
$$

とする。氷の顕熱を無視するため $T_s$ の蓄熱項はない。このモデルの一定潜熱による定義であり、塩水や融解水の詳細なエンタルピーを表現するものではない。

5 節の更新は、氷の発生・消滅も含めて

$$
\boxed{\mathcal E_o^{\rm new}-\mathcal E_o
=\Delta\tau\{(1-A)F_{\rm ow}(T_o)+AF_i(T_s)\}}
$$

を満たす。$A$ の上下限制約で $V$ を減らさないので、面積制限によって熱は消えない。

格子全体では

$$
\mathcal E_{\rm sfc}=f_L(C_LT_L+C_dT_d)+f_O\mathcal E_o
$$

とし、大気へ渡す顕熱、蒸発潜熱、上向き長波には表面から引いたものと同じ数値を使う。したがって物理更新の表面・大気間の交換は相殺される。RAW や大気の他の数値処理まで含む全積分の厳密保存を、この局所収支式だけから主張しない。

## 7. 大気・放射との結合順序

大気へ渡す格子平均フラックスは

$$
H=w_LH_L+w_{\rm ow}H_o+w_iH_i,\qquad
E=w_LE_L+w_{\rm ow}E_o,
$$

$$
L_\uparrow=\sigma(w_LT_L^4+w_{\rm ow}T_o^4+w_iT_s^4),
\qquad
\alpha_{\rm grid}=w_L\alpha_L+w_{\rm ow}\alpha_o+w_i\alpha_i
$$

とする。$\sigma(w_LT_L+w_{\rm ow}T_o+w_iT_s)^4$ は用いない。$\alpha_{\rm grid}$ は地表の反射率であり、雲の反射を別途加える既存の短波方式を維持する。

現行の [物理評価](../../core/src/tendency/dry/dry_tendency_evaluator.f90) の順序を基礎に、次の順で処理する。

1. 前時刻の大気・陸・海・海氷・バケツから $E_L,E_o$ を求め、面積平均した蒸発を大気の比湿傾向へ加える。
2. 既存どおり対流調節・大規模凝結（雪を含む）・雲診断を行う。
3. 大気の透過率・放射源と雲量から、地表の $S_\downarrow,L_\downarrow$ を求める。
4. 各表面の顕熱・放射を求め、海氷の $T_s$ を診断する。
5. $L_\uparrow$ を長波の下端境界に渡して上向き掃き出しを行い、大気加熱率と OLR を求める。顕熱も同じタイル値を平均して大気へ渡す。
6. 陸の二層（雪があれば積雪と融雪）と、5 節の海水・海氷の更新量を計算する。
7. 陸バケツを更新する。

現在の灰色放射では下向き長波は地表からの上向き長波に依存しない。短波も地表・雲間の多重反射を持たないため、$T_s$ の探索ごとに大気の放射計算全体をやり直す必要はない。氷面の昇華を 0 とするため、蒸発と氷表面温度の間にも循環依存は生じない。

## 8. 時間レベルと RAW 後の制約

### 8.1 物理更新の幅

[物理過程を評価する時刻](./physics-time-level.md) と同じく、物理の大気・地表入力は RAW 適用済みの前時刻とする。太陽位置と雲の診断時刻は既存規約に従う。海氷の $T_s$ だけは、この入力の熱収支を満たす値を同じ評価内で解く。

[積分器](../../core/src/integration/dry_stepper.f90) の `centered_interval` を $\Delta\tau$ として渡す。通常は $2\Delta t$、初期化の二段階はそれぞれ $\Delta t/2$ と $\Delta t$ であり、どちらも $X^0$ から候補を作る。候補更新を二段階分累積してはいけない。

海水・氷の更新は単なる局所微分ではなく、時間幅を受け取って相変化を確定する手続きとする。傾向のインターフェースを使う場合は、5 節で求めた $(X^{\rm new}-X^{\rm old})/\Delta\tau$ を返し、積分器で同じ $\Delta\tau$ を一度だけ掛ける。

$T_L,T_d,T_o,A,V,W$ は格子量として保持し、水平移流・スペクトル変換・重力波の陰解法・超粘性は適用しない。

### 8.2 RAW フィルターによる相の混在

既存と同じ RAW 係数を $T_L,T_d,T_o,A,V$ に適用する。しかし $T_o,A,V$ を独立にフィルターした直後は、負の体積や暖水と氷の共存が生じ得る。現在のバケツのように $V$ だけを切り上げると潜熱が失われる。

そこで、RAW が返した `filtered` と `next` の**両方**に以下を適用する。フィルター直後を添字 $r$ で表し、$V_r$ を切り上げる前に

$$
\mathcal E_r=C_o(T_{o,r}-T_f)-\mathcal L V_r
$$

を保存する。

- $\mathcal E_r\ge0$: $V=0,A=0,T_o=T_f+\mathcal E_r/C_o$。
- $\mathcal E_r<0$: $V=-\mathcal E_r/\mathcal L,T_o=T_f$。$A=\min(1,\max(0,A_r))$ とし、それでも $A=0$ なら $A=\min(1,V/h_0)$ として正の氷面積を与える。

これはフィルター後の合計エネルギーを保つ相平衡への補正である。フィルター自体のエネルギー変化を取り消す操作ではない。同じ線形 RAW を $T_o,V$ に適用するため、$\mathcal E_r$ は $\mathcal E_o$ を RAW に通した値と丸め誤差の範囲で一致する。

面積の補正は数値処理であり、5.4 節の物理的な面積更新とは別に診断する。特に RAW によって氷が再出現した際の $V/h_0$ は再初期化の規則であり、物理的な開水面凍結量には数えない。補正前後の $A,V,T_o$ の差とエネルギー残差を記録し、補正の頻発・大きさと時間刻み依存性を検証する。

### 8.3 不変条件と欠損タイル

候補、RAW 後の二つの状態、初期状態のすべてで、海がある格子は

$$
0\le A\le1,\quad V\ge0,\quad
V=0\Longleftrightarrow A=0,\quad
T_o\ge T_f,\quad V>0\Longrightarrow T_o=T_f
$$

を満たす。NaN/Inf はクリップせず失敗とする。純陸では $A=V=0$ に固定して海の計算を呼ばず、純海では陸温度・地中温度・バケツの更新を呼ばない。非存在タイルと格子配列のパディングは有限のダミー値で保持し、集計・物理計算から除外する。氷がないときの出力 $h,T_s$ は 0 を欠損の代用とし、必ず $A>0$ のマスクと組み合わせる。

物理的な氷厚下限や $V$ の上限は今回追加しない。微小な氷を便宜的に消す操作も加えず、薄氷の計算は 5.2 節のスケーリングで扱う。

## 9. 初期条件・設定・互換性

初期化では `set_surface_state` に渡された初期地表温度を $T_L,T_o$ にコピーし、$A=V=0$ から始める。$T_o$ を別に渡した場合はその値を使う。海氷を使う計算ケースは $T_o$ に $T_f$ 以上の解析的な分布を渡すので（[湿潤ケース](../cases/moist.md#初期値)）、次の変換は起こらない。海氷を有効にした場合、初期の海水が $T_f$ を下回る格子だけ

$$
V=\frac{C_o(T_f-T_{o,0})}{\mathcal L},\qquad
A=\min(1,V/h_0),\qquad T_o=T_f
$$

として初期エネルギーを保存する。初期の氷量を明示指定するインターフェースでは範囲と相平衡を検証し、不整合な入力を黙って変更しない。初期化した全地表場は `current` と `previous` に同じ値を設定する。

`dry_model_physics_config` に `sea_ice_config` を追加し、`enabled`、$T_f,T_m,h_0,k,\rho_i,L_f,\alpha_i$ と表面解法の許容値・反復上限を保持する。既存の定数管理に合わせて既定値は設定型に一度だけ置く。正の熱容量・厚さ・密度・潜熱・伝導率、$0\le\alpha\le1$、$0<T_f\le T_m$ を検証する。

有効化するケースは次のとおり。

| ケース / 設定 | 温度と海氷の扱い |
| --- | --- |
| `moist` | 全海洋のタイル経路で海氷を有効化 |
| `land`, `land-t63`, `land-earth`, `land-earth-t63` | 陸海別温度と海氷を有効化 |
| 陸海混合を使い `sea_ice.enabled=false` | 陸海別温度は使い、海水の凍結制限を外す。$A=V=0$ |
| 既存の乾燥 `radiation`, `slab-ocean` | 海氷は既定で無効。従来の単一地表経路とアルベドを保持 |
| `slab-ocean` で明示的に海氷を有効化 | 全海洋のタイル経路を使い、海と氷のアルベドを明示する |
| 放射が無効、または海洋を持たない設定で海氷を要求 | 設定エラー |

海氷有効経路では、雲の反射を織り込んだ従来の一様アルベド 0.3 と裸氷アルベドを混ぜない。雲無効なら雲反射も 0 とする。旧設定を使う比較ケースとこの物理的な違いをメタデータで区別する。

純陸・無氷純海は対応する既存の方程式に戻るが、海岸格子は温度分離と地中熱容量の変更によって結果が変わる。陸海ケース全体のビット一致は互換性要件としない。既存出力の読み込みは維持し、既存出力ファイルを上書きして新仕様に読み替えることはしない。

## 11. 出力と診断

既存の `surface_temperature` は

$$
T_{\rm surface}=w_LT_L+w_{\rm ow}T_o+w_iT_s
$$

という表面温度の面積平均として残す。これは海水温でも長波の実効放射温度でもない。`ocean_temperature` は氷の下も含む混合層温度であることを明記する。既存の陸平均温度は $T_L$、海平均温度は $T_o$ から計算する。

月平均と年次瞬時値に、陸温度、海水温、海氷面積率 $A$、海面積当たり体積 $V$、氷厚 $h$、氷表面温度 $T_s$ を追加する。月平均 $A,V$ は海に対する通常の時間平均とし、氷厚と氷表面温度は氷が存在する面積・時間で重み付けする。

$$
h_{\rm month}=\frac{\sum_t A_t h_t\,\delta t}{\sum_t A_t\,\delta t}
=\frac{\sum_t V_t\,\delta t}{\sum_t A_t\,\delta t},\qquad
T_{s,\rm month}=\frac{\sum_t A_tT_{s,t}\,\delta t}{\sum_t A_t\,\delta t}.
$$

分母が 0 の場所は欠損マスクを付ける。年次瞬時値で状態と対応する $T_s$ を出す際は、保存状態と出力時刻の入力から診断し直す。ステップで使ったフラックスの $T_s$ と混同せず、物理フラックスの集計には実際の更新に使った値を保持する。

日次・全球診断には次を追加する。

- 海氷面積 $\int f_OA\,dS$ と体積 $\int f_OV\,dS$、氷面積で重み付けした平均氷厚。
- 物理更新の局所エネルギー残差と、氷表面のスケーリングした残差 $hF_i+k(T_f-T_s)-hM$ の最大絶対値。
- RAW 後の `filtered` と `next` に対する $A,V,T_o$ の補正量とエネルギー残差の最大絶対値、補正した格子数と検査した格子数。補正数は各量の $32\epsilon\max(1,|X|)$ を超える変化を数え、日内の全検査を合計する。

残差と補正量は日内の最大値で、エネルギーの単位は海面積当たり $\mathrm{J\,m^{-2}}$、表面残差は $\mathrm{W\,m^{-1}}$。月平均は一定時間刻みでの等間隔サンプルである。`mean_deep_temperature_k` はタイル経路では陸面積平均を表す。

全海洋・全陸・無氷では、存在しない領域の集計値を既存方式に合わせて 0 とし、有効面積も一緒に記録する。メタデータには面積の分母、体積の単位、定数、海氷有効フラグ、昇華なし、温度出力の意味、時間レベル・補正方式を記録する。

## 12. 実装の受入条件

実装時に、少なくとも以下を単一格子の数値検証と結合検証で確認する。

| 条件 | 確認する結果 |
| --- | --- |
| 暖かい無氷海の加熱・冷却 | $T_o^*\ge T_f$ の間は $A=V=0$、従来の slab 更新と一致 |
| 無氷海が $T_f$ を下回る | 不足熱量を $\mathcal L$ で割った新氷、$A=V/h_0$（上限内）、$T_o=T_f$ |
| 部分被覆した海の開水面冷却 | $(1-A)$ を一度だけ掛ける。$f_L$ を変えても同じ海タイル入力なら同じ $A,V,T_o$ |
| 新氷が海を埋め尽くす | $A=1$ に制限しても体積・潜熱を失わない |
| $T_s<T_f$ の氷面冷却 | $G(T_s)=0$、$\Delta V_{\rm surf}=0$、底面成長、海水の二重冷却なし |
| $T_f<T_s<T_m$ | 表面融解は 0、底面融解は負 |
| 表面温度が $T_m$ を超えそうな加熱 | $T_s=T_m$、表面の正の残差だけが表面融解、伝導を含めた収支が閉じる |
| 全面結氷 $A=1$ | 開水面フラックスは 0。氷面の放射・顕熱だけで成長・融解が進む |
| 融解して氷が残る | 新氷なしなら $A^{\rm new}=A\sqrt{V^{\rm new}/V}$ に一致。消滅に近づくと面積も連続的に 0 へ近づく |
| 開水面生成と氷面融解が同時に起きる | $\Delta V$ の正・0・負をそれぞれ試し、5.4 節の面積則に一致 |
| ちょうど消滅・大幅に融け過ぎる | $A=V=0$、余剰熱だけで $T_o$ が上昇、融解源によらず同じ熱保存 |
| 微小な正の $A,V$、薄氷 | ゼロ除算・非有限値なし、スケーリングした表面残差が許容内 |
| 陸海で違う温度 | 蒸発・顕熱・長波を別々に求め、面積平均が大気の入力と一致 |
| 純陸・純海・無効設定 | 非存在タイルを更新しない。旧検証経路の回帰を維持 |
| 初期化の二段階と通常ステップ | 実更新幅が $\Delta t/2,\Delta t,2\Delta t$。相変化の二重適用なし |
| RAW で負の $A,V$・暖水と氷の共存を作る | `filtered` と `next` の両方で不変条件を満たし、補正前後の $\mathcal E_r$ が一致 |
| 保存・コピー・交換・出力 | 新状態がすべて引き継がれ、欠損タイルや月平均の氷厚を誤集計しない |

符号を確認する単純な例として、$A=0.25,T_o=T_f$、$F_{\rm ow}=-100\,\mathrm{W\,m^{-2}}$、$\Delta\tau=1200\,\mathrm s$ なら、開水面成分は $Q_{\rm ow}=-90000\,\mathrm{J\,m^{-2}}$、$\Delta V_{\rm ow}\simeq2.93850685\times10^{-4}\,\mathrm m$、$\Delta A_{\rm ow}\simeq5.87701369\times10^{-4}$ になる。

体積収支の別の例として、$A=0.4,V=0.2\,\mathrm m$ から新氷生成なしに $\Delta V=-0.1\,\mathrm m$ なら $A^{\rm new}=0.4\sqrt{0.5}\simeq0.2828427,V^{\rm new}=0.1\,\mathrm m$。$\Delta V=-0.25\,\mathrm m$ なら全消滅し、$\widehat T_o=T_f$ の場合は余剰の $0.05\mathcal L$ により $T_o$ が約 $0.12195\,\mathrm K$ 上がる。

物理更新のエネルギー残差は入力熱量と丸め誤差に応じた許容値で判定し、表面解法の残差を別に確認する。結合計算では時間刻みを半分にした比較で海氷面積・体積、熱収支、RAW 補正が収束するかを調べる。短い結合検証と既存テストの合格後に季節変化を含む計算を行い、範囲制約の達成だけで妥当性を判断しない。

## 13. 参照範囲

この設計の生成・融解・面積更新の規則は今回の依頼を基準としている。表面温度が融点未満の枝と融点に固定する枝の区別、および表面熱と伝導熱を分ける考え方の確認には [Icepack 1.5.1 の Thermodynamics](https://cice-consortium-icepack.readthedocs.io/en/icepack1.5.1/science_guide/sg_thermo.html) を参照した。同資料の多層・塩分・積雪モデルや定数を本仕様として採用したわけではない。
