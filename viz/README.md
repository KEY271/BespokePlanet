# BespokePlanet visualizer

`output/` にある陸海ケースの計算結果を 3D 地球と 2D 正距円筒図法で表示し、気候を解析します。以前の `scripts/` の R スクリプト（`analyze_moist_land_sea*.R`、`snow_sea_ice_map.R`）と、地形の確認図を描く Python スクリプトはすべてここに移しました。

対象は海氷と積雪を含む最新の陸海ケース（`just run land` / `land-t63` / `land-earth` / `land-earth-t63`）だけです。メタデータの `schema_version` が 3 以上で、湿潤大気、`sea_ice.enabled` と `snow.enabled` が真であり、解析に使う月平均の場が1年分以上そろっている出力だけが一覧に出ます。

## 起動

```sh
just visualizer        # または just viz
just visualizer 8080   # ポートを変える
```

ブラウザで <http://127.0.0.1:8000> を開きます。直接起動する場合は次のとおりです。

```sh
cd viz
npm install
python3 server.py --output /path/to/output --port 8080
```

Python 側に外部パッケージは不要です。Three.js は `npm install` で `viz/node_modules/` に置かれ、サーバーから配信されます。`http://127.0.0.1:8000/?run=moist_land_sea_t31` のように `run` でケースを指定して開けます。

## 画面上部の設定

- **ケース**: 表示するケース。
- **解析する年**: 気候値を計算する年（12 か月がそろった年、既定は最後の年）。以前の R スクリプトは最後の 12 か月だけを使っていました。
- **陸とみなす陸面率 f_L ≥**: 陸とみなす陸面率の閾値（0.01–1、既定 0.5）。スライダーか数値で変えると、陸の判定を使うものがすべてその場で計算し直されます。
  - ケッペンの気候区分と陸だけの地図（陸でないセルは海の色）、海氷の地図（陸のセルは陸の色）、雪と海氷の地図
  - 海岸線（陸と陸以外のセルの境界）
  - 代表地点の吸着先（閾値以上のセルのうち最も近いセル）と雨温図
  - 要約の陸に関する量（最低・最高気温、南北極域の陸温と地上気温、区分の面積割合など）
  - 閾値はブラウザに保存され、次に開いたときも使われます。

陸面率そのもので重みを付ける量（陸面積平均の温度・雲量・P − E など）は閾値に依存しません。外洋の地表気圧偏差は、以前と同じく閾値と別の $f_L\le0.01$ を外洋とします。

## 01 地図

画面の表示はすべて日本語です（CSV の列名は以前の R スクリプトと同じ英語のままです）。

「表示する場」から選びます。どの場も元の octahedral 格子のセル（経度区間 × 緯度リングの境界）をそのまま塗ります。格子点 $k$ の経度は $360k/n_j$ 度で、2D 地図は本初子午線を中央に置きます。

- **解析年の気候値**（R スクリプトの地図と同じ区切りと配色）
  - ケッペン–ガイガーの気候型（Peel et al. 2007）、ケッペンの気候群。C/D 境界はどちらも −3 °C で、気温は地上気温（下記）
  - 陸の年平均地上気温、陸の年平均地表温度、陸の年降水量、陸のバケツの水、陸の P − E
  - 年平均の雲量、降水量と地表気圧の JJA − DJF
  - 外洋の年平均地表気圧の偏差（地形のリップルの確認）
  - 3 月・9 月の雪と海氷（陸は積雪率 $f=S/(S+S_0)$、それ以外は海氷面積率）、3 月・9 月の海氷面積率
  - 海氷の面積加重平均の厚さと表面温度
- **月平均**: 全期間の月平均の地表場（温度、地上気温、気圧、降水・蒸発、雲量、バケツ、積雪、海氷など）。

ケッペン区分・雨温図・代表地点の気温は、ソルバーが出力する月平均の地上気温 `surface_air_temperature`（最下層の気温を地表気圧まで乾燥断熱で外挿した $T_N(p_s/p_N)^\kappa$、[地面](../docs/tendency/ground.md)の顕熱と同じ値）を使います。陸タイルの表面温度 `land_temperature` は、夏の裸地で空気より大きく暖まるので使いません。
- **年次の瞬時値（4月1日）**: 毎年 4 月 1 日の瞬時値。地表場と、「層」で選ぶモデル層の温度・風・比湿・渦度・発散。`log_surface_pressure` は地表気圧（hPa）に直して表示します。
- **時間変化しない場**: 陸面率、陸の標高（閾値で陸とみなしたセルだけを R スクリプトの区切りで塗る）、地表高度、海洋の Q フラックス。

存在しないタイル（純海洋の陸温度、純陸の海水温、氷のないセルの氷の厚さなど）は灰色で塗り、色の範囲の統計から除きます。温度は °C、気圧は hPa で表示します。

- 「海岸線」閾値で決めた海岸線、「代表地点」代表地点（番号は雨温図と共通）、「格子点」格子点、「流線」年次の瞬時値の選択した層の風の流線（「流線の本数」で本数）。
- 地図にポインターを置くとセルの位置・値・陸面率・気候型を表示し、クリックしたセルの雨温図を解析パネルに加えます。
- 時間のある場は再生・スクラブできます。「色の範囲」は表示中のフレームの 0.5–99.5 パーセンタイル（符号のある場はゼロ中心）、ラン全体の範囲、現在の範囲の固定から選びます。
- 「PNG 保存」で表示中の地図（3D・2D）を、題・表示中の時刻・凡例（画像の下）・ケースと閾値をつけて保存します（代表地点の番号ラベルは含みません）。
- 「一括 ZIP 保存」（「要約と CSV」タブにもある）で、時間変化しない結果をまとめた `<ケース>_year<年>_fL<閾値>.zip` を保存します。月平均と年次の瞬時値の地図は含みません。
  - `maps/climatology/`: 解析年の気候値の地図すべて。`maps/static/`: 時間変化しない場の地図（連続量の色の範囲は 0.5–99.5 パーセンタイル）。どちらも正距円筒図法で描き直し、凡例を地図の下につけます。海岸線と代表地点の番号は画面の「海岸線」「代表地点」の設定に従います。
  - `charts/`: 雨温図（代表地点と選択したセル）、帯状平均、質量流線関数、海氷、全期間の時系列。題・凡例つき。
  - `csv/`: 「要約と CSV」の CSV すべてと、雨温図の月別値 `final_year_climographs_monthly.csv`。
  - `README.txt`: ケース・解析年・閾値と中身の一覧。

## 02 解析

解析する年の 12 か月の月平均から、ブラウザ内（`static/climate.js`）で計算します。

| タブ | 内容 |
| --- | --- |
| 雨温図 | 代表地点（解析的な地形では大陸の内部など 6 点、地球地形では実在の 12 地点と観測の気候型）とクリックしたセルの雨温図。代表地点は縦軸を共有し、縦軸は全データを含む。気温は地上気温 |
| 帯状平均 | 年平均の地表温度、降水量と蒸発量、雲量の帯状平均（陸と海を含む） |
| 質量流線関数 | 月平均の帯状平均 $v$ と $p_s$ から求めた年平均の質量流線関数 |
| 海氷 | 南北半球別の海氷面積・体積の季節変化 |
| 時系列 | `daily_global.csv` の全期間の全球平均（地表温度、降水と蒸発、可降水量、大気上端の正味放射、海氷の面積・体積・厚さ、陸の積雪） |
| 比較 | 別の陸海ケース（既定は地形の種類が違う同じ解像度のケース）との帯状平均・全球平均の比較 |
| 要約と CSV | 要約の表（以前の `analysis_summary.csv` の全項目と閾値、閾値で陸とみなしたセルの面積）、代表地点の表、CSV の保存 |

保存できる CSV は以前の R スクリプトと同じ名前と列です（`final_year_koppen_groups.csv` には閾値による陸の判定 `is_land` と年平均の地上気温 `annual_mean_surface_air_temperature_c` を加え、代表地点の気温は地上気温 `annual_mean_surface_air_temperature_c` にしています）: 要約、全セルの年平均と気候区分、代表地点、雨温図の月別値、帯状平均、質量流線関数、海氷の月別集計。各グラフは「PNG 保存」で保存できます。
