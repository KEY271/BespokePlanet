# 陸海ケース

[湿潤ケース](./moist.md)の aquaplanet に、[地形](../dynamics/topography.md)で生成した大陸と山脈を加え、地表を[陸と海の混合](../tendency/land-sea-surface.md)で扱う計算ケースの定義である。力学の傾向項は[湿潤大気](../dynamics/moist.md)のとおりに解く。$T=31$ と $T=63$ の両方で同じ惑星を計算できるようにする。

## 湿潤ケースとの差分

次の点を湿潤ケースから変更する。

- 地表ジオポテンシャル $\Phi_s$ に、[地形](../dynamics/topography.md#既定の惑星)の既定の惑星から生成した値を使う。$\Phi_s$ は積分中ずっと固定する。
- 同じ生成から得た陸面率 $f_L$ を地表収支に渡し、熱容量・アルベド・湿り具合・地中との熱交換を[陸と海の混合](../tendency/land-sea-surface.md)のとおり混ぜる。陸は[地面](../tendency/ground.md)の二層モデル、海は深さ $30\,\mathrm{m}$ の [slab ocean](../tendency/slab-ocean.md) である。地中温度 $T_d$ を予報変数として持つ。
- 初期値は[地形上の初期状態](../dynamics/topography.md#地形上の初期状態)のとおり、放射ケースの基本場を気圧の関数として読み、地表面気圧を $\Phi^\ast(\varphi,p_s)=\Phi_s$ から決める。
- 出力に陸面率・地表高度の静的な場と、陸と海で分けた全球平均を加える。

[雲](../tendency/cloud.md)、[短波放射](../tendency/shortwave-radiation.md)、[長波放射](../tendency/longwave-radiation.md)、[オゾン](../tendency/ozone.md)、[乾燥対流調節](../tendency/dry-convective-adjustment.md)、[湿潤対流調節](../tendency/moist-convective-adjustment.md)、[大規模凝結](../tendency/large-scale-condensation.md)、地表摩擦、[上層の Rayleigh 摩擦](../tendency/upper-rayleigh-friction.md)、[暦と軌道](../calendar.md)（地軸の傾き $23.4^\circ$）、自転角速度、計算期間、タイムステップ、超粘性の時定数は湿潤ケースと同じとする。すべての物理過程は[物理過程を評価する時刻](../tendency/physics-time-level.md)のとおり $\overline X^{n-1}$ の場で評価する。

## 地表のパラメータ

| 量 | 陸 | 海 |
| --- | --- | --- |
| 熱容量 | $C_s=2\times10^6\,\mathrm{J\,m^{-2}\,K^{-1}}$（浅い層）、$C_d=2\times10^7$（深い層） | $C_o=1.2558\times10^8\,\mathrm{J\,m^{-2}\,K^{-1}}$ |
| 地中との熱交換 | $K_{sd}=2\,\mathrm{W\,m^{-2}\,K^{-1}}$ | なし |
| 短波アルベド（雲を含まない） | $\alpha_L=0.2$ | $\alpha_o=0.06$ |
| 湿り具合 | $\beta_L=0.5$ | $\beta_o=1$ |

格子点の値はこれらを $f_L$ で線形に混ぜたものである。雲の反射は[雲](../tendency/cloud.md)で診断した雲量から別に計算するので、アルベドは地表そのものの値である。$\beta_L$ が陸の気候を決める主要なパラメータで、5 年平均の陸上の $\braket{P}_L-\braket{E}_L$ と $\braket{T_s}_L$ を見て見直す。

## 解像度

湿潤ケースと同じく、まず $T=31$ で 5 年積分して水収支と気候が破綻していないことを確かめ、その後 $T=63$ で走らせる。両方の解像度で同じ地形の定義を使うので、$T=31$ で見た $z_s$ と $f_L$ の切断の影響（負の行き過ぎ、RMS 差）が $T=63$ で小さくなることを確認する。鉛直層数 $N=12$、タイムステップ $\Delta t=1200\,\mathrm{s}$ はどちらの解像度でも変えない。$T=63$ の放射ケースが同じ $\Delta t$ で走っているので、地形による重力波は陰解法で扱える範囲にある。移流の CFL は最大風速の診断で監視する。

ケースは切断波数を引数に取り、$T=31$ と $T=63$ をそれぞれ `land` と `land-t63` で走らせる。出力先は `moist_land_sea_t31` と `moist_land_sea_t63` とし、両方を並べて比較できるようにする。

## 初期値

[地形上の初期状態](../dynamics/topography.md#地形上の初期状態)のとおり、格子の $\Phi_s$ から各格子点の $p_s$ を決め、full level の気圧で JW の温度と釣り合った東西風を評価する。比湿の初期値は湿潤ケースと同じ相対湿度 $\mathrm{RH}_0=0.7$、$p_{\mathrm{top}}=200\,\mathrm{hPa}$ とし、各格子点の $p_s$ から作った full level の気圧を使う。$T_s,T_d$ は最下層の温度 $T_N$ に等しくする。海上では $\Phi_s$ の切断のリップルを除いて湿潤ケースの初期値と同じである。

## 時間

湿潤ケースと同じく $5$ 年間、すなわち $5\times360$ 太陽日シミュレーションする。タイムステップは $\Delta t=1200\,\mathrm{s}$ とする。

## 出力

湿潤ケースの出力に次を加える。ファイル名の規則、日平均・月平均・毎年の瞬時値の定義は湿潤ケースと同じとする。

積分の開始時に一度だけ、時間に依らない格子の場を書く。

- 陸面率 $f_L(\lambda,\varphi)$
- 格子の地表高度 $z_s(\lambda,\varphi)$（切断後、m）

1 日ごとの日平均量には、[陸と海の混合](../tendency/land-sea-surface.md#診断)の定義で次を加える。湿潤ケースで海洋温度と読み替えていた全球平均 $\braket{T_s}$ は、陸と海を合わせた地表温度の全球平均に戻す。

- 陸上・海上の地表温度 $\braket{T_s}_L,\braket{T_s}_O$
- 陸上・海上の降水 $\braket{P}_L,\braket{P}_O$
- 陸上・海上の蒸発 $\braket{E}_L,\braket{E}_O$
- 地中温度の全球平均 $\braket{T_d}$

30 日ごとの月平均量には次を加える。

- 各格子点の地中温度の月平均 $T_d(\lambda,\varphi)$

毎年の 4/1 の瞬時値には、放射ケースと同じく格子の $T_d$ とスペクトルの $T_d$ を加える。

メタデータには、地形の形状一覧とパラメータ、全球の陸面率 $\braket{f_L}$、格子の $z_s$ の最大・最小と解析形との RMS 差、陸と海のパラメータの表、切断波数を書く。

## 実装の手順

各モジュールの役割は変えず、次の順に手を入れる。設定値は既存の物理設定と同じくデフォルト初期化子に一か所で書く。

1. 地形の生成。[地形](../dynamics/topography.md)の形状（楕円大陸・極冠・山脈）とパラメータを持つ設定型と、任意のスペクトル変換に対して格子の $f_L$ と $z_s$、切断したスペクトル $\Phi_s$、診断量（$\braket{f_L}$、$z_s$ の最大・最小、RMS 差）を返す生成手続きを、[浅水方程式](../dynamics/shallow-water-equation.md)の孤立した山の初期値と同じ形で一つのモジュールにまとめる。
2. ソルバーの境界場。乾燥大気のソルバーは $\Phi_s$ を固定の境界場として持っているので、同じ扱いで格子の $f_L$ を持たせ、初期状態を入れるときに $\Phi_s$ と一緒に渡す。指定がなければ $f_L\equiv0$（海）または $f_L\equiv1$（陸）を既存ケースの指定から決める。物理過程の作業領域に $f_L$ の格子を置く。
3. 地表収支の混合。放射の気柱計算に $f_L$ を渡し、熱容量・アルベド・湿り具合・地中との熱交換を[陸と海の混合](../tendency/land-sea-surface.md)のとおり混ぜる。蒸発の傾向にも混ぜた $\beta$ を渡す。slab ocean を選ぶ論理値は $f_L\equiv0$ に読み替える。
4. 地形上の初期状態。JW の初期値の手続きに $\Phi_s$ を渡せるようにし、[地表面気圧](../dynamics/topography.md#地表面気圧)の反復と[各層の値](../dynamics/topography.md#各層の値)の気圧による評価を加える。$\Phi_s=0$ を渡したときに既存の平坦地形の経路とビット単位で一致させる。
5. ケース。湿潤ケースの物理設定を継承して地形と陸海の設定を加えたケース関数、切断波数を引数に取るケース本体、コマンドライン引数 `land`・`land-t63` を加える。
6. 出力。静的な場、日平均の陸海別の列、月平均・瞬時値の $T_d$、メタデータの地形と陸海の項を加える。
7. 確認。下の確認項目を単体試験にし、既存ケースとの一致を確かめてから 5 年積分を走らせる。

## 実装後の確認項目

陸海ケースを走らせる前に、次を単体試験で確認する。

- 地形の生成を $T=31$ と $T=63$ で行い、格子で $0\le f_L\le1$、解析形の $z_s\ge0$ となること。切断後の $z_s$ の最小値が $-50\,\mathrm{m}$ を下回らず、解析形との RMS 差が $T=63$ で $T=31$ より小さいこと。全球の陸面率 $\braket{f_L}$ が両解像度で $0.5\%$ 以内で一致すること。
- 既定の惑星のパラメータが $T=31$ の[解像度の条件](../dynamics/topography.md#解像度との関係)を満たすこと。
- 地表面気圧の反復が $|\Phi^\ast(p_s)-\Phi_s|<10^{-6}\,\mathrm{m^2\,s^{-2}}$ で収束し、$\Phi_s=0$ の格子点で $p_s=p_0$ が厳密に得られること。
- $\Phi_s\equiv0$ を渡した地形上の初期状態が、放射ケースの平坦地形の初期状態とビット単位で一致すること。
- $f_L\equiv1$ で放射ケース、$f_L\equiv0$ で slab ocean ケースと湿潤ケースの数ステップの積分が、混合を入れる前とビット単位で一致すること。
- $0<f_L<1$ の気柱で、大気に加える顕熱・潜熱・長波と地表・地中から差し引く値の和が丸め誤差の範囲で $0$ になること。$f_L$ を $0$ から $1$ まで変えたとき $C,\alpha,\beta,K$ と蒸発 $E$ が線形に変わること。
- 地面と最下層の温位が等しい乾燥断熱中立な気柱で、$f_L$ の値に関わらず顕熱フラックスが $0$ になること。
- 既定の惑星の地形の上で、物理過程を持たない乾燥大気を 1 日積分し、最大の南北風と全球の発散の RMS が平坦地形の場合と比べて桁で大きくならないこと。

5 年積分の後には次を確認する。

- 日平均の $\braket{P}$ と $\braket{E}$ が定常状態で一致し、$\braket{W_\pm}$ の日々の差分と $\braket{E}-\braket{P}$ の差が $\braket{P}$ に比べて小さいこと（湿潤ケースと同じ）。
- 月平均の $T_s(\lambda,\varphi)$ が海岸で単調に変わり、海側に陸の日変化のリップルが漏れていないこと。
- 陸上の $\braket{T_s}_L$ の日変化と季節変化が海上より大きく、$\braket{P}_L-\braket{E}_L>0$（陸への正味の水輸送）となっていること。$\beta_L$ はこの結果を見て見直す。
- 山脈の風下で地表面気圧と降水の分布に定在的な構造が現れること。$T=31$ と $T=63$ の月平均を並べ、地形に対する応答の大きさが解像度で大きく変わらないこと。
