# 地球地形の陸海ケース

[陸海ケース](./land-sea.md)の解析的な大陸と山脈を、[地球の地形](../dynamics/earth-topography.md)から生成した $\Phi_s$ と $f_L$ に置き換えた計算ケースの定義である。物理過程・初期値の手順・時間・出力は陸海ケースと同じで、地形の生成元だけが違う。$T=31$ と $T=63$ の両方で計算する。

## 陸海ケースとの差分

- 地表ジオポテンシャル $\Phi_s$ と陸面率 $f_L$ を `generate_topography` の代わりに `generate_earth_topography` で作る。中間ファイル `core/data/earth_topography_0p5deg.bin` を読み、切断波数に応じた幅 $s=c\cdot180^\circ/T$（$c=1.25$）の Gauss 核で平滑化してから $\Phi_s$ を切断する。
- 地表のパラメータ（$C_s,C_d,C_o,K_{sd},\alpha_L,\alpha_o$ と[バケツモデル](../tendency/bucket.md)の $W_{\max},W_0$）、雲、放射、対流調節、大規模凝結、摩擦、暦（地軸の傾き $23.4^\circ$）、自転角速度、$N=12$、$\Delta t=1200\,\mathrm{s}$、超粘性は陸海ケースと同じとする。地球の地形でもバケツのパラメータを変えない。陸海ケースの結果と比べるとき地形以外の差を持ち込まないためである。
- 出力先は `moist_land_sea_earth_t31` と `moist_land_sea_earth_t63` とし、コマンドライン引数は `land-earth` と `land-earth-t63` とする。`all` にも加える。
- メタデータの `topography` を[地球の地形](../dynamics/earth-topography.md#出力)のとおり中間ファイルの由来と診断量に置き換え、`initial_condition` の文字列を地球地形である旨に変える。

## 解像度

陸海ケースと同じく、まず $T=31$ で 5 年積分して水収支と気候が破綻していないことを確かめ、その後 $T=63$ を走らせる。$c$ は両解像度で同じ値を使うので、平滑化の幅は $T=31$ で約 $7.3^\circ$、$T=63$ で約 $3.6^\circ$ である。$T=31$ ではアンデス・ロッキー・アルプスのような細い山脈は大きく低くなり、チベット・南極・グリーンランドの高原はおおむね残る。$T=63$ では細い山脈も半分程度の高さで残る。両者の差が地形に対する応答の解像度依存を表すので、月平均の $p_s$・降水・$T_s$ を並べて比較する。

チベットと南極の上では $p_s$ が $600$–$700\,\mathrm{hPa}$ になり、重力波の陰的演算子の参照状態との差が陸海ケースより大きい。$\Delta t=1200\,\mathrm{s}$ で不安定になった場合は $\Delta t=900\,\mathrm{s}$（太陽日を割り切る）に下げ、メタデータに記録する。

## 初期値

[地形上の初期状態](../dynamics/topography.md#地形上の初期状態)のとおり、格子の $\Phi_s$ から各格子点の $p_s$ を決め、full level の気圧で JW の温度と釣り合った東西風を評価する。比湿の初期値、$T_s=T_d=T_N$ とバケツの $W=W_0$ は陸海ケースと同じである。

## 時間

$5$ 年間、すなわち $5\times360$ 太陽日シミュレーションする。

## 出力

陸海ケースと同じ。静的な場 `land_fraction.bin` と `surface_height.bin`、日平均の陸海別・バケツの列、月平均の $T_d,W,\beta_L,R$、毎年の瞬時値をそのまま書く。

## 実装の手順

1. **前処理スクリプト** `scripts/prepare_earth_topography.py` で ETOPO 2022 を $6'$ に間引いて取得し、中間ファイルと JSON を `core/data/` に作る（済）。中間ファイルと JSON はリポジトリに入れる。
2. **確認スクリプト** `scripts/plot_earth_terrain.py` で $c$ と $T$ の走査表と図を出し、$c=1.25$ が[地球の地形](../dynamics/earth-topography.md#走査の結果)の基準を満たすことを確かめた（済）。Fortran 実装後にメタデータの診断値と表を突き合わせる。
3. **生成モジュール** `core/src/earth_topography.f90` に `earth_topography_config`、中間ファイルの読み込み、Gauss 核の平滑化、切断、残差フィルター、診断を書く（済）。読み込みは `access='stream'`、`convert='little_endian'` で出力と対称にする。パスは `data/...` と `core/data/...` を順に試す。核の窓は緯度帯と、$\sin(\theta/2)\ge\cos\varphi_{\max}\sin(\Delta\lambda/2)$ による経度の前判定で絞り、緯度リングで OpenMP 並列にする。
4. **ケース** `radiation_case.f90` に `land_earth_variant` を加え、`run_land_earth_case`・`run_land_earth_t63_case` と `case_runners` の引数、`justfile`・`README.md` の一覧を加える（済）。
5. **出力** `radiation_case_output.f90` の `topography` の書き出しを地形の種類で分け、地球地形のときは中間ファイルの由来と診断量を書く（済）。
6. **単体試験** `core/test/check_earth_topography.f90` に[地球の地形](../dynamics/earth-topography.md#fortran-側の確認項目)の項目と、下の確認項目を書く（済）。
7. **積分** $T=31$ の 5 年積分、確認、$T=63$ の 5 年積分。

## 実装後の確認項目

積分の前に単体試験で確認する。

- [地球の地形](../dynamics/earth-topography.md#fortran-側の確認項目)の項目すべて。
- 地球の地形の上で、物理過程を持たない乾燥大気を 1 日積分し、最大の南北風と全球の発散の RMS が解析的な地形の場合と比べて桁で大きくならないこと。$T=31$ と $T=63$ の両方で行う。平坦地形は $v\equiv0$ から始まるので比較の基準にはせず、発散の参考値として出すだけにする（実測は[地球の地形](../dynamics/earth-topography.md#力学への影響)）。
- 地表面気圧の反復がすべての格子点で収束し、最小の $p_s$ が $500\,\mathrm{hPa}$ 以上であること（実測 $629$・$565\,\mathrm{hPa}$）。
- 解析的な地形の陸海ケースの結果がビット単位で変わらないこと（生成元の分岐を加えても既存の経路に手を入れないため）。

5 年積分の後には陸海ケースの確認項目に加えて次を確認する。

- 月平均の $p_s$ を海上で見て、南大洋・アンデス西岸・グリーンランド周辺に $\pm3\,\mathrm{hPa}$ を超える定在的な帯状・同心円状のリップルがないこと。あれば $c$ を上げて再生成する。
- 月平均の $T_s$ が海岸で単調に変わること。特にアンデス西岸・南極の縁・グリーンランドの縁を見る。
- 全球の陸面率が約 $0.29$ で、陸上の定常な水収支 $\braket{P}_L-\braket{E}_L-\braket{R}_L\simeq0$ を満たすこと。
- 北半球の夏に南アジア・東アジアの陸上で降水が増え、冬に減ること（季節風の向き）。チベットの風下と風上、アンデスの東西で降水に差があること。$T=63$ で差が大きくなること。
- 南極と北極周辺の $T_s$ が陸海ケースの南極冠と同程度に低いこと。雪氷は扱わないので、アルベドは $\alpha_L=0.2$ のままである。
