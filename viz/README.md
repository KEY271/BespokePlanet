# BespokePlanet visualizer

`output/` に保存された順圧渦度方程式、浅水方程式、および乾燥静力学大気の計算結果を、3D 地球と2D 正距円筒図法で表示します。順圧・浅水ケースでは保存量診断も表示します。放射・slab ocean・湿潤・陸海ケースは月平均の地表場を表示し、年次瞬時値は名前に `.yearly` が付いた別の選択肢になります。陸温度・海水温・海氷面積率・体積・氷厚・氷表面温度に対応し、存在しないタイルは灰色で表示して色範囲の統計から除きます。鉛直場と日平均 CSV は引き続き `scripts/` の R スクリプトで解析します。従来の海氷場を持たない出力も読み込めます。

## 起動

プロジェクト内のどのディレクトリからでも、次のコマンドで起動できます。

```sh
just visualizer
```

ポートを変更する場合は引数で指定します。

```sh
just visualizer 8080
```

`just viz` も同じ動作です。直接起動する場合は以下を実行してください。

```sh
cd viz
npm install
python3 server.py
```

ブラウザで <http://127.0.0.1:8000> を開いてください。別の出力ディレクトリを読む場合は `--output` を指定できます。

```sh
python3 server.py --output /path/to/output --port 8080
```

Python 側には外部パッケージは不要です。Three.js は `npm install` で `viz/node_modules/` に配置され、Python サーバーからローカル配信されます。

## 表示内容

- 表示する場をヘッダーの `FIELD` から選択
  - 順圧渦度方程式: `zeta`、`sqrt(u² + v²)`
  - 浅水方程式: `zeta`、`delta`、`eta`、`sqrt(u² + v²)`
  - 乾燥大気: 地表面気圧、温度、`zeta`、`delta`、東西風 `u`、南北風 `v`、`sqrt(u² + v²)`
- 乾燥大気の3次元場はヘッダーの `LEVEL · p₀ REF.` からモデル層を選択
  - 各選択肢には、地表面気圧を基準値 `p₀` としたときの層中心の目安気圧を hPa で表示
  - 表示値は等圧面への補間ではなく、選択した hybrid-sigma 層の予報値を直接使用
- 隣接する緯度リングを三角形化し、選択した場を連続した面として表示
- `STREAMLINES` で、同じ時刻・モデル層の水平風 `u/v` から追跡した流線を重ねて表示
  - reduced Gaussian grid 上の風を経度方向および緯度リング間で補間し、球面上で前後方向へ積分
  - 3D 地球と2D地図で同じ流線を表示し、移動する点で風向を示す
  - 強い風ほど流線を黄緑色に近づけ、移動点を速くしてジェットを判別しやすくする
  - `DENSITY` で流線の本数を `LOW` / `MEDIUM` / `HIGH` から変更
- `GRID POINTS` で元の格子点を面の上に重ねて表示
- 符号を持つ場はゼロ中心のカラースケール
- `3D GLOBE` / `2D MAP` トグルで、同一フレームの回転可能な球面表示と正距円筒図法を切り替え
- 2D 正距円筒図法は、経度 360° × 緯度 180° に対応する厳密な 2:1 の表示領域
- フレーム再生、時刻スクラブ、再生速度変更
- Gaussian 求積による平均運動エネルギー、平均絶対エンストロフィー、平均相対渦度、平均相対軸角運動量の時系列

カラースケールは `SCALE` から切り替えられます。`AUTO · P99.5` は表示中フレームの 0.5–99.5 パーセンタイル（符号を持つ場では絶対値 99.5 パーセンタイルを使うゼロ中心の範囲）を使い、細かな構造も見やすくします。`GLOBAL` はラン全体の範囲、`LOCK CURRENT` は現在の範囲を以後のフレームでも維持します。概要欄の `MAX` は表示中フレームの実際の最大値（符号を持つ場では最大絶対値）です。

ケースを読み込むたびにブラウザ内のフレームキャッシュを破棄し、フレームAPIもHTTPキャッシュを使用しません。シミュレーションを再実行して同名ケースを更新した場合も、以前のデータや統計ヘッダーが混在しないようにしています。

流線は瞬間的な水平風ベクトルに沿う線であり、空気塊の時間発展を追う経路線ではありません。`LEVEL` を変更すると、表示場が地表面気圧の場合でも流線は選択した大気層へ追従します。
